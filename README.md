# First Project 🚀

This is my first project created mainly for **practice and learning**. I am currently learning how to use **Git and GitHub**, and this project is a way for me to understand the basic workflow of version control and managing projects online.

Through this project, I am practicing things such as:

* Creating and managing a Git repository
* Using Git commands from the terminal
* Adding and committing changes
* Understanding Git branches
* Connecting a local project to GitHub
* Pushing changes from my computer to GitHub
* Making changes and tracking different versions of my project
* Writing and formatting a `README.md` file using Markdown

This project is not intended to be a complex or production-level project. The main goal is to become comfortable with **Git, GitHub, and the overall development workflow**.

As I continue learning programming and data science, I plan to use GitHub to store my projects, track my progress, and gradually build my portfolio.

This is just the beginning! 🌱
